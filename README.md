# Math Covering

Ce projet est un site vitrine conçu à titre de démonstration pour une future activité de covering et de detailing automobile. L'objectif était de proposer une première version d'un futur site web pour cette activité tout en me permettant de mettre en pratique et d'approfondir mes compétences en intégration web, responsive design, manipulation du DOM en JavaScript et gestion de version avec Git.

## Fonctionnalités

- Présentation des différentes prestations proposées.
- Galerie des projets réalisés.
- Page de tarifs permettant de consulter les offres proposées.
- Formulaire de contact permettant aux visiteurs de demander un devis.
- Localisation de l'entreprise grâce à une carte interactive.

## Technologies utilisées

### Front-end

- HTML5
- CSS3
- JavaScript

### Outils

- Git
- GitHub

### Services externes

- Google Fonts
- Google Maps Embed

## Ce que j'ai appris

- Création d'une interface responsive adaptée aux ordinateurs et aux appareils mobiles.
- Manipulation du DOM avec JavaScript pour ajouter des interactions utilisateur.
- Débogage et résolution de problèmes lors du développement.
- Utilisation de Git pour gérer les versions du projet et suivre son évolution grâce aux commits.
- Publication d'un projet sur GitHub.
